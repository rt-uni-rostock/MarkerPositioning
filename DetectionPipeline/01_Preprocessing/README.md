# Preprocessing

## Ideen:

In diesem Pipeline-Schritt werden die rohen Bilder entgegengenommen und vorverarbeitet, damit im nächsten Schritt die Marker erkannt werden können.
Mögliche Vorverarbeitungsschritte sind:
- **Kontrast einstellen**: damit der Marker sichtbarer wird
- **in Graustufen umwandeln**: um die Verarbeitung zu vereinfachen
